## Bagian 1: Pemanasan

1. Pada aturan `nav a.active:hover { color: red; }`:
   - Selector: `nav a.active:hover`
   - Deklarasi: `color: red;`
   - Property: `color`
   - Value: `red`
   - Pseudo-class: `:hover`

2. Jenis elemen berdasarkan tampilan default:
   - Inline: `span`, `a`, `strong`
   - Block: `p`, `h2`
   - `li`: `list-item`, yaitu elemen daftar yang secara default ditampilkan sebagai item list.

3. Paragraf yang menjadi hijau adalah **A dan B**, karena keduanya merupakan elemen `p` yang berada di dalam elemen dengan class `box`.

4. Warnanya **merah**. Selector `#title` memiliki specificity lebih tinggi daripada `.heading` dan `h1`, sehingga aturan `color: red;` diterapkan.

5. Kesalahannya adalah tag HTML tidak ditutup dengan urutan yang benar. Tag `<strong>` dibuka di dalam `<p>`, tetapi tag `<p>` ditutup lebih dahulu. Perbaikan:
   `<p>Hello <strong>world</strong></p>`
